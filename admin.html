      Le réglage est mémorisé dans ce navigateur uniquement (sans cookie). Sur un autre appareil ou un autre navigateur, ouvrez une fois iashark.com/?internal=1 (et ?internal=0 pour annuler). Sont aussi exclus d'office : les visites liées à un compte administrateur ou de test, les tests automatisés (robots, Playwright, E2E), les liens utm_source=qa…. Les copies locales et les prévisualisations Netlify n'envoient jamais de statistiques.

      Définitions. Visiteur = un onglet de navigateur ayant vu au moins une page (identifiant effacé à la fermeture de l'onglet, aucun cookie). Visite = période d'activité ; une nouvelle visite commence après 30 minutes d'inactivité. Durée = temps passé avec l'onglet au premier plan (30 min maximum par page). Rebond = visiteur n'ayant vu qu'une page. Pays = estimation depuis le fuseau horaire du navigateur. Sans cookie, un visiteur qui revient un autre jour est compté comme nouveau.

      Trafic exclu par défaut. Vos propres visites (appareil exclu), les comptes admin et de test, les tests QA (liens utm_source commençant par « qa »), les navigateurs pilotés (robots, tests automatisés, écrans émulés) et les visites exclues à la main. Activez « Inclure mon trafic / tests » pour les voir.
