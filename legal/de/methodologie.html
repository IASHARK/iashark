2. Verwendete Daten

Die Analysen stützen sich auf Statistiken zu Mannschaften und Spielern, auf frühere Spiele und auf die Quoten, die Buchmacher anbieten. Wie viele Daten verfügbar sind, hängt vom Wettbewerb ab.

3. So funktioniert es

Für jedes Spiel schätzt ein statistisches Modell anhand dieser Daten die Chancen der wichtigsten Ausgänge. Die Analyse hebt dann eine Option hervor, die nach einer festen Regel unter den Märkten gewählt wird, für die Buchmacher tatsächlich Quoten anbieten; die wahrscheinlichsten Ausgänge haben dabei Vorrang. Gibt es für ein Spiel keine Quote, wird die wahrscheinlichste Option ohne Quote veröffentlicht.

Ein Werkzeug der künstlichen Intelligenz verfasst anschließend den erläuternden Text auf Grundlage der bereits berechneten Zahlen: Es wählt nichts aus und kann keine Zahl verändern. Die Texte werden automatisch, mit einem KI-Werkzeug, in die anderen Sprachen der Website übersetzt.

4. Was die Zahlen bedeuten

Eine Wahrscheinlichkeit ist eine Schätzung, niemals ein Versprechen. 60 % bedeutet, dass das Ereignis über sehr viele vergleichbare Spiele hinweg etwa 6-mal von 10 eintreten sollte und etwa 4-mal von 10 nicht. Auf der Website wird die geschätzte Wahrscheinlichkeit auch auf einer Skala bis 10 angezeigt: 6,4/10 entspricht 64 %.

IAShark veröffentlicht die Ergebnisse des Vortags, eingetroffene wie nicht eingetroffene Märkte, ohne Rentabilitätszahlen und ohne Gewinnversprechen.

5. Grenzen

  • Unvorhergesehenes. Die Analysen werden im Voraus einmal täglich erstellt und kurz vor dem Anpfiff nicht aktualisiert. Eine Verletzung in letzter Minute, eine unerwartete Aufstellung oder andere Überraschungen werden nicht berücksichtigt. Prüfen Sie immer die offiziellen Aufstellungen.
  • Kleine Stichproben. Zu Saisonbeginn oder bei einem Aufsteiger liegen nur wenige Spiele vor: Die Schätzungen sind dann unsicherer.
  • Enthaltung. Für ein bereits begonnenes Spiel oder bei unzureichenden Daten wird keine Option hervorgehoben.
  • Von KI verfasste Texte. Sie werden vor der Veröffentlichung nicht einzeln geprüft und können Interpretationsfehler enthalten. Bei Abweichungen gelten die angezeigten Zahlen.
  • Zufall. Fußball bleibt sehr unberechenbar: Verlustserien kommen auch dann vor, wenn die Schätzungen stimmen. Setzen Sie niemals Geld ein, das Sie benötigen.
  • Keine Wetten auf dieser Website. IAShark veröffentlicht Analysen: Die Website nimmt keine Einsätze entgegen.
